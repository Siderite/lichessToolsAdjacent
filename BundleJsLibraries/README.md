# Bundle js libraries
Create js bundle for bundling various js libraries

Instructions: 
1. run **npm run build** or **generate.bat**
2. copy **chessops.bundle.mjs** from Output into the LiChess Tools **tools/chessops** folder
3. copy **d3.bundle.mjs** from Output into the LiChess Tools **tools/d3** folder
4. copy **nouislider.bundle.mjs** from Output into the LiChess Tools **tools/nouislider** folder
